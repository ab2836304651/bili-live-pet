  兔团子桌宠 · 快速使用说明
══════════════════════════════════

【这是什么】
  一只会看你直播间弹幕的桌面兔团子：
  观众发弹幕/送礼物 → 兔团子开口回应（气泡显示）。
  不需要安装 Python，双击即用。

【第一次使用（1 分钟搞定）】
  1. 双击  兔团子桌宠.exe  启动
  2. 首次会自动弹出【设置面板】，填两样东西：
     ① 直播间房间号 = 你直播间网址 live.bilibili.com/ 后面的数字
     ② API Key = 在 https://platform.deepseek.com 注册后
        点「API Keys」-> 创建新密钥 -> 复制 sk- 开头的串
  3. 点「📱 扫码登录」-> 手机 B 站 App 扫一扫 -> 手机上确认
     （扫码后 B站登录态自动填好，必须做，不然收不到弹幕）
  4. 点【保存】，兔团子出现，开播就收弹幕了

【以后每次】
  直接双击 兔团子桌宠.exe 启动即可。

【想改桌宠性格？】
  右键兔团子 ->「⚙️ 设置」-> 切到「提示词」页，改完保存。
  写清楚它叫什么、什么性格、怎么说话，重启生效。

【B站登录态过期了？】
  B站登录态约 30 天有效，过期后收不到弹幕。
  右键兔团子 ->「⚙️ 设置」-> 直播间页 -> 重新扫码即可。

【出问题了？】
  · 桌宠不回复 → 直播间有人发弹幕吗？
    （冷清房间可能好几分钟才有一条弹幕，属正常）
  · 提示"收不到弹幕" → B站登录态过期，重新扫码
  · 提示"AI 调用失败" → API Key 没填对或余额不足
  · 其它问题 → 把截图发给送你桌宠的人
